# 화면 흐름 (아트 · UI 제작용)

> 팀에 공유할 때는 이쪽: [ForagerCP — 화면 흐름 (아트 · UI 제작용)](https://claude.ai/code/artifact/a25acdc5-58ef-4b27-ab3f-9c2da4c93eae) — 같은 내용이고, 거기서 바로 고치거나 코멘트를 달 수 있다.

지금 붙어 있는 화면 전부를 실제 빌드에서 찍었다. **디자인은 전부 갈아엎어도 된다** —
지금 것은 기능을 확인하려고 만든 임시 UI다.

스크린샷: [`docs/flow/`](flow/)

_기준: 2026-10-12 · 커밋 `2fa9e43` · 1920×1080_

## 1. 흐름도

```
                            ┌──────────────┐
                 ESC  ◄────►│   04 메뉴    │
                            └──────┬───────┘
                                   │ 버튼
                        ┌──────────┴──────────┐
                        ▼                     ▼
                 ┌─────────────┐      ┌──────────────┐
                 │  05 스킬    │      │ 06 저장 슬롯 │
                 └─────────────┘      └──────────────┘

   ┌──────────────┐
   │   01 HUD     │  ◄── 게임을 하는 동안 늘 떠 있다
   └──────┬───────┘
          │
          ├─ I ─────────────────────►  03 가방
          │
          ├─ E (핫바에서 블럭 선택) ─►  02 설치  ──► 월드에 오브젝트
          │
          └─ F (대상 2m 안) ────┬────►  07 제작대
                                ├────►  08 상점
                                ├────►  09 판매 (변환기)
                                ├────►  10 보관함
                                └────►  구역 벽 (입장료 지불)
```

**모든 창은 ESC로 닫는다.** 하위 화면에서 ESC → 메뉴로, 메뉴에서 ESC → 완전히 닫힘.
창이 떠 있는 동안 게임 입력(이동·공격·채집)은 끊긴다.

## 2. 화면별

### 01 HUD — [`01_HUD.png`](flow/01_HUD.png)

늘 떠 있는 것. **지금 제일 급조된 화면이고, 새로 디자인할 여지가 가장 크다.**

| 자리 | 지금 | 담는 정보 |
|------|------|----------|
| 좌상단 | 검은 패널 + 글자 | 레벨 / 경험치(현재 ÷ 다음) / 가방 요약 / 골드 |
| 좌하단 | 빨간 네모 10개 | 체력 (하트 1칸 = 2) |
| 하단 중앙 | 9칸 + 이름표 | 핫바. 고른 칸은 금색 테두리, 칸마다 개수 |

> 가방 요약을 좌상단에 글로 쭉 늘어놓는 건 임시다. 가방 창이 따로 있으니 HUD에서는
> 빼거나 아이콘 몇 개로 줄여도 된다.

### 02 설치 — [`02_설치한_보관함.png`](flow/02_설치한_보관함.png)

핫바에서 설치 가능한 것을 고르고 **E**. 커서가 가리키는 칸에 반투명 표식이 뜨고
(놓을 수 있으면 초록, 없으면 빨강), 사거리는 4m.
놓인 뒤 다가가면 하단에 **F 프롬프트**가 뜬다 — 지금은 검은 바탕 + 글자.

### 03 가방 — [`03_가방.png`](flow/03_가방.png)

**I** 또는 메뉴에서. 20칸(상점 확장 시 40칸)이 격자로. 칸마다 색 칩 + 이름 + 개수.
하단에 `사용 칸 / 전체 칸 · 총 개수`.

> 색 칩은 아이콘이 없어서 쓰는 대체물이다. **아이콘이 들어오면 자동으로 아이콘이 이긴다**
> (에셋에 아이콘을 넣기만 하면 됨). 색은 아이템 종류마다 고정값이라 순서가 바뀌어도 안 변한다.

### 04 메뉴 — [`04_메뉴.png`](flow/04_메뉴.png)

**ESC**. 우측에 버튼 세로 배치 — 스킬 / 저장.

### 05 스킬 — [`05_스킬.png`](flow/05_스킬.png)

격자형. 가운데에서 시작해 **4방향 이웃으로 뻗는다**. 레벨업마다 포인트 1.
칸 상태가 셋이다: **해금됨 / 지금 찍을 수 있음 / 아직 잠김** — 셋이 눈에 확 갈라져야 한다.

> 지금 13칸은 자리만 잡은 더미다. 실제 스킬 목록은 기획 대기.

### 06 저장 슬롯 — [`06_저장슬롯.png`](flow/06_저장슬롯.png)

슬롯 3개. 슬롯마다 레벨 / 골드 / 플레이 시간 / 마지막 저장 시각, 비었으면 "빈 슬롯".
불러오기 · 저장 · 삭제.

### 07 제작대 — [`07_제작대.png`](flow/07_제작대.png)

**F**. 좌: 제작법 목록(아이콘·이름·재료·시간·만들기 버튼). 재료가 모자라면 **빨간 글씨로 사유**.
우: 제작 중 슬롯 2개 — 진행 바 + 남은 시간, 취소 버튼. 완성되면 수령 버튼.
하단 좌: 지금 낀 도구.

### 08 상점 — [`08_상점.png`](flow/08_상점.png)

**F**. 품목 9종이 줄로. 아이콘 · 이름 · 설명 · 가격 · 사기 버튼.
**선행 품목을 안 샀으면 줄 자체가 안 뜬다.** 줄이 많아 스크롤이 붙어 있다.

### 09 판매 — [`09_판매.png`](flow/09_판매.png)

**F** (변환기). 팔 수 있는 광물이 줄로. 줄마다 수량을 −/+/전부로 고르고 예상 골드를 보여준 뒤 판다.

### 10 보관함 — [`10_보관함.png`](flow/10_보관함.png)

**F**. 격자 둘 — 좌: 보관함 20칸(제목에 구역 이름), 우: 가방.
**칸을 누르면 반대쪽으로 통째로 넘어간다.** 자리가 모자라면 들어간 만큼만 옮기고 하단에 안내.

## 3. 아트가 자유롭게 바꿔도 되는 것 / 코드가 같이 바뀌는 것

| 자유 | 말해주면 같이 고치는 것 |
|------|----------------------|
| 색 · 폰트 · 테두리 · 배경 · 여백 · 연출 | **칸 수** (가방 20/40, 보관함 20, 핫바 9) |
| 창 크기와 위치, 요소 배치 | **격자 → 목록** 같은 구조 변경 |
| 아이콘 (에셋에 넣으면 색 칩을 자동으로 대체) | **조작 방식** (칸 클릭 → 끌어놓기 등) |
| 버튼 모양 · 상태별 스프라이트 | **새 정보** (지금 안 보여주는 값을 띄우고 싶을 때) |
| 패널에 장식 더하기 | **화면 추가 · 진입 경로 변경** |

지금 UI는 **SlimUI Modern Menu 1** 에셋의 프레임·버튼 스프라이트를 쓰고 있다.
다른 걸로 가도 되고, 그 경우 스프라이트만 갈아끼우면 된다.

## 4. 아직 화면이 없는 것

| 무엇 | 왜 없나 |
|------|---------|
| 타이틀 · 시작 화면 | 아직 안 만듦 |
| 사망 · 부활 화면 | 패널티 수치가 미정(K4) |
| 몬스터 공격 예고 표시 | 기획 확인 대기 — 있다면 **무엇으로 보여줄지** 결정 필요 |
| 구역 지도 / 미니맵 | 요구 없음 |
| 보스 (M6) | 엔드게임, 미착수 |
