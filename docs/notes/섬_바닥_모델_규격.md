# 섬(구역 바닥) 모델 — 받는 법 · 넣는 법

_작성 2026-11-11 · 바다 3단계(섬 몸통) 시작 전_

구역마다 섬 모델 하나를 받아 `Land_<구역>`에 꽂는다.
그 전까지는 구역 사각형으로 자동 생성한 **임시 몸통**이 자리를 채운다. 모델이 오면 몸통의 "보이기"만 끄고 충돌은 그대로 쓴다.

---

## 1. 아트에 넘길 것 (전달 규격)

### 좌표 · 크기
| 항목 | 규격 | 이유 |
|---|---|---|
| 단위 | 1 unit = 1 m, Y 위 | 그리드 1칸 = 1m |
| 원점(피벗) | **월드 원점 (0,0,0)** 에 맞춰 월드 좌표 그대로 모델링 | 씬에 (0,0,0)으로 놓으면 바로 맞는다. 구역마다 피벗을 따로 계산할 일이 없다 |
| 윗면 높이 | **y = 0** (걷는 면) | 플레이어·광물·구조물이 전부 0을 바닥으로 놓여 있다 |
| 절벽 깊이 | **y = −3 이하까지** 세로로 내린다 | 잠긴 섬은 −3m에 가라앉아 있다. 그보다 얕으면 솟기 전부터 바닥이 보인다 |
| 해안선 | 아래 표의 **구역 외곽선에서 ±0.25m 안** | 해안 거품은 구역 칸 경계를 기준으로 그린다. 모델이 더 나가거나 들어가면 거품과 땅 사이가 뜨거나 땅 위로 거품이 올라온다 |
| 물 높이 | y = −0.15 | 절벽 윗부분 0.15m는 물 위로 보인다 |

### 구역 외곽 (월드 좌표, m)
칸 (0,0)의 **중심**이 월드 원점이라 칸 경계는 .5에 걸린다.

| 구역 | 사각형 (x 범위 · z 범위) |
|---|---|
| 첫 들판 | x −18.5 ~ −5.5 · z −5.5 ~ 11.5 / x −5.5 ~ 14.5 · z −0.5 ~ 11.5 |
| 바위 지대 | x −18.5 ~ 14.5 · z 11.5 ~ 17.5 / x 14.5 ~ 23.5 · z −0.5 ~ 17.5 / x −18.5 ~ −8.5 · z 17.5 ~ 25.5 |
| 수정 지대 | x −8.5 ~ 14.5 · z 17.5 ~ 25.5 |

> 구역 볼륨(`Regions` 밑 `RegionVolume`)을 고치면 이 표도 바뀐다. 모델링 시작 전에 최신 값을 다시 뽑아서 넘길 것.
> 임시 몸통을 OBJ로 내보내 **참고용 블록아웃**으로 같이 넘기면 가장 정확하다(아래 4번).

### 파일 · 재질
| 항목 | 규격 |
|---|---|
| 파일 | FBX, 구역당 1개. 이름 `Island_<구역영문>.fbx` (`Island_Field`, `Island_Rocks`, `Island_Crystal`) |
| 폴더 | `Assets/_Project/Art/Models/Island_<구역>/` + `Textures/` (기존 광물 모델과 같은 구조) |
| 텍스처 | 최대 2048. 윗면과 절벽은 머티리얼을 나눠도 된다 |
| 셰이더 | URP Lit 기준으로 확인 |
| 넣지 말 것 | 충돌체 · 조명 · 카메라 · 애니메이션 (충돌은 임시 몸통 것을 그대로 쓴다) |
| 위에 놓이는 것 | 광물·구조물·나무는 모델에 굽지 않는다 — 배치 팔레트로 따로 놓아야 캐고 저장된다 |

## 2. 받았을 때 확인할 것 (5분)

1. 씬에 (0,0,0)으로 끌어다 놓고, 임시 몸통과 겹쳐 본다 — 외곽이 ±0.25m 안에 들어오는가
2. 윗면이 y=0인가 (광물 밑이 뜨거나 묻히지 않는가)
3. 절벽 바닥이 −3 이하인가
4. 정면이 뒤집혀 있지 않은가 (이전 광물 모델은 180° 돌아 와서 손으로 고쳤다)
5. 임포트 설정: 애니메이션 끔 · 머티리얼 추출 · 스케일 1 · 텍스처 2048 (기존 모델과 동일)

## 3. 넣는 법

```
Islands
└ Land_Rocks            ← RegionLand (구역 · 몸통 · 스포너)
  └ Ground              ← RegionLand의 "몸통" 칸이 가리키는 곳. 솟을 때 이걸 통째로 든다
    ├ Blockout          ← 임시 몸통 (IslandBlockout). 모델이 오면 "보이기"만 끈다 — 충돌은 계속 쓴다
    └ Island_Rocks      ← 받은 모델을 여기 (0,0,0)으로
```

1. 모델을 `Land_<구역>/Ground` 밑에 위치 (0,0,0)으로 넣는다
2. 같은 곳의 `Blockout`에서 **보이기** 체크를 끈다
3. 플레이해서 걸어 본다 — 절벽 끝에서 떨어지지 않고, 가장자리에 거품이 붙는지

첫 들판은 지금 바닥 타일 461개가 몸통 노릇을 한다. 섬 모델이 오면 타일 폴더를 지우고 같은 방법으로 넣는다.

## 4. 참고용 블록아웃 내보내기

`Blockout` 컴포넌트 우클릭 → **OBJ로 내보내기** → `Assets/_Project/Art/Models/Island_<구역>/Blockout_<구역>.obj`
아트는 이걸 불러와 위에 덮어 모델링하면 외곽·높이가 자동으로 맞는다.
